# Capstone Projects

Rather than a single end-of-course project, this course requires seven capstones, each one a progressively more realistic deliverable. The early projects are research exercises on historical data; the middle projects produce working software with test suites; the final projects run live against a broker and are operated like production systems. Each capstone builds on the artifacts of the previous ones, so by the end you have a working end-to-end trading stack — data, research, backtesting, portfolio construction, execution, and operations — rather than a collection of isolated notebooks.
