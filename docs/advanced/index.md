# Optional Advanced Modules

These modules are for experienced learners who have completed the core parts of the course and want depth in a specific area. Each module is self-contained: it states its own prerequisites, and none of the capstones depend on any of them. Take the ones relevant to the roles or markets you are targeting — an execution researcher needs the impact and Almgren–Chriss modules; someone heading toward derivatives desks needs stochastic calculus and options pricing; nobody needs all thirteen.

| Module | Focus |

| [Particle and Kalman Filters](02-particle-and-kalman-filters.md) | State-space models, dynamic hedge ratios, non-Gaussian filtering |
| [Stochastic Calculus](03-stochastic-calculus.md) | Brownian motion, Itô calculus, SDEs, continuous-time models |
| [Optimal Execution: Almgren–Chriss](04-optimal-execution-almgren-chriss.md) | Implementation shortfall and optimal trade scheduling |

| [Alternative Data](07-alternative-data.md) | NLP, satellite, filings; point-in-time hygiene and vendor evaluation |
| [GPU Acceleration with CUDA](08-gpu-acceleration-cuda.md) | CuPy, Numba, GPU-accelerated backtests and training |
