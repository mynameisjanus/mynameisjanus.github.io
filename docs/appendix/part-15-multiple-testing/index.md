# Part XV — Multiple Testing

What happens to error rates when many hypotheses are tested — the central statistical hazard of strategy research. Corrections (Bonferroni, FDR) and the trading-specific tests (White's Reality Check, Hansen's SPA) that account for a searched universe of strategies.

| Topic | Focus |

| [Bonferroni Correction](02-bonferroni-correction.md) | Controlling family-wise error by dividing the level |
| [False Discovery Rate](03-false-discovery-rate.md) | Controlling the expected fraction of false positives |
| [Data Snooping Bias](04-data-snooping-bias.md) | How repeated strategy testing manufactures false discoveries |
| [White's Reality Check](05-whites-reality-check.md) | A bootstrap test for the best strategy in a searched universe |
| [Hansen's SPA Test](06-hansens-spa-test.md) | A studentized improvement on White's Reality Check |
